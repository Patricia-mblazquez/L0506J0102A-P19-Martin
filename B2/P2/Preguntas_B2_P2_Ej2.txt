2. ¿Quién y cómo se genera la señal de CS para el display?
Enlace 1 -> En Pin Description (pagina 6): 
	Pin No. |	Symbol	|	External Connection	|	Function Description
	17	|	 /CS1	|	MPU 			|	Active LOW Chip Select signal

- La señal de CS la genera el microcontrolador (MPU) conectado al display
- Se activa en nivel bajo (LOW) para habilitar la comunicacion SPI con el diplay
